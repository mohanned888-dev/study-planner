# مدار — Space Edition 2.0.1

**Designed and developed by mohanned**

عالمك الخاص للمذاكرة: واجهة عربية مستوحاة من النجوم والفضاء، بأسود هادئ وتفاصيل فضية وبنفسجية. النسخة كاملة وتحافظ على أدوات المذاكرة الموجودة في النسخة الأولى.

## شغّل الموقع مباشرة

1. فك ضغط الملف وافتح المجلد.
2. افتح **index.html** الموجود في أول المجلد على اللابتوب بمتصفح حديث.
3. جاهز. النسخة دي ملف واحد يحتوي على التصميم والكود والخطوط، ويعمل بدون إنترنت.

على الموبايل، استخدم رابط الموقع من المتصفح؛ معاينة HTML داخل تطبيق الملفات قد لا تشغّل JavaScript.

## النشر على Vercel

هذه النسخة تتضمن **vercel.json** بإعدادات البناء ومجلد النشر، لتجنب خطأ انتظار مجلد public.

- ارفع **محتويات المجلد** كاملة، بما فيها `src` و`dist` و`build.mjs` و`package.json` و`vercel.json`. لا ترفع ZIP إلى GitHub كبديل للملفات.
- يجب أن يظهر `package.json` و`vercel.json` في جذر الريبو. لو المجلد كله اسمه Madar داخل الريبو، اختَر Madar كـRoot Directory في Vercel.
- إعدادات هذه النسخة: Framework = Other، Build Command = `node build.mjs`، Output Directory = `dist`. ملف vercel.json يحدد الإعدادات تلقائيًا عند النشر.
- إذا كانت النسخة القديمة متصلة بالمشروع، حدّث ملفات المصدر وانشر أحدث commit من فرع النشر. إعادة نشر نسخة Vercel Drop القديمة لا تضيف تعديلات GitHub.
- بديل بسيط: استضف **index.html** الموجود في أول المجلد وحده كصفحة ثابتة دون build أو ملفات أخرى.

## ماذا يوجد في النسخة؟

- خلفية نجوم متلألئة، حركة هادئة، كوكب SVG أصلي بحلقات، واجهة داكنة افتراضية، ووضع فاتح اختياري.
- الحركة تتوقف عند إخفاء الصفحة وتحترم إعداد تقليل الحركة. لا توجد صور أو خطوط تُحمّل من مواقع خارجية.
- لوحة يومية بالمهام والوقت والاختبارات والتقدم في المواد.
- مهام قابلة للإضافة والتعديل والحذف والإنجاز، بأولويات ومواعيد وأوقات تقديرية وبحث وفلاتر.
- جدول أسبوعي بمواعيد فردية أو متكررة وكشف التعارضات.
- «خطّط لي»: توزيع تلقائي للمهام غير المكتملة بحسب الأولوية والموعد، يراعي الوقت المتاح والمواعيد الحالية والحد اليومي، مع ١٠ دقائق بين الجلسات ومعاينة قبل الاعتماد. ليس خدمة AI ولا يحتاج API.
- مؤقت تركيز قابل للتخصيص، وراحة قصيرة أو طويلة بعد كل أربع جلسات، وتشغيل وإيقاف واستكمال، وربط بمادة أو مهمة.
- المؤقت يحسب موعد النهاية حتى عند تغيير التبويب. عند إغلاق الصفحة، تُسجَّل جلسة واحدة مكتملة عند العودة إذا حان وقتها؛ الاستراحة لا تبدأ تلقائيًا. صوت النهاية يحتاج الصفحة مفتوحة وسماح المتصفح بتشغيل الصوت.
- مواد بموضوعات يمكن إكمالها. التقدم محسوب من الموضوعات المكتملة.
- اختبارات بعدّ تنازلي وإضافة مهام مراجعة.
- بطاقات سؤال وإجابة بفواصل مراجعة بسيطة. الصعبة تعود في الجلسة نفسها، والمواعيد تتباعد كلما تذكّرت الإجابات بسهولة.
- ملاحظات قابلة للبحث، بألوان وتثبيت وربط بمادة.
- إحصائيات آخر ٧ أيام، وتوزيع وقت المواد، وخريطة نشاط ٨ أسابيع وشارات إنجاز.
- تصدير واستيراد JSON، وتصدير المواعيد والاختبارات إلى ICS، وطباعة الجدول والتقرير.
- واجهة RTL متجاوبة مع الموبايل والكمبيوتر، ودعم لوحة المفاتيح.

## البيانات والحفظ

التطبيق يبدأ بأمثلة تجريبية واضحة. اضغط «ابدأ ببياناتك» من الرئيسية لإزالتها بعد التأكيد.

البيانات تُحفظ في localStorage على نفس الجهاز والمتصفح وعنوان الموقع. لا توجد حسابات أو مزامنة سحابية بين الأجهزة. صدّر نسخة JSON من الإعدادات قبل مسح بيانات المتصفح أو نقل الموقع لعنوان آخر. الاستيراد يستبدل البيانات بعد التأكيد ويوقف المؤقت الجاري.

النسخة الجديدة تحافظ على نفس مفتاح التخزين `madar.study.v1`، وتستوعب نسخ JSON القديمة. أول فتح بعد التحديث يفعّل الستايل الداكن مرة واحدة مع الإبقاء على موادك ومهامك. يمكنك بعدها اختيار الوضع الفاتح من الإعدادات.

الجلسة المكتملة تعني اكتمال المؤقت، ولا تثبت انتباه المستخدم. لا توجد إشعارات خلفية عند إغلاق الصفحة، ولا يرسل الموقع البيانات إلى خادم.

## ملفات الكود

| الملف | وظيفته |
|---|---|
| `index.html` | نسخة متكاملة للفتح مباشرة؛ يولدها أمر البناء |
| `src/index.html` | هيكل الصفحة والكريديت الذي يظهر أسفل كل صفحة |
| `src/styles.css` | التصميم الكامل والتجاوب، وقسم Space Edition في آخر الملف |
| `src/core.js` | منطق التواريخ والتخطيط والمؤقت والمراجعة والتحقق من النسخ الاحتياطية |
| `src/app.js` | الواجهة والتخزين والتنقل والنماذج |
| `src/space.js` | خلفية النجوم، بدون مكتبات |
| `dist/` | النسخة المنظمة الجاهزة للاستضافة والخطوط المحلية |
| `build.mjs` | يولد dist والنسخة المتكاملة باستخدام Node.js فقط |
| `vercel.json` | إعدادات البناء والنشر على Vercel |
| `tests/core.test.cjs` | اختبارات الوظائف الأساسية |
| `FONT-LICENSE.txt` | ترخيص الخطوط المحلية |

## التعديل والبناء

**عدّل الملفات داخل src.** تعديل index.html الموجود في أول المجلد مباشرة سيُستبدل عند البناء.

هذه النسخة لا تحتاج Python ولا npm install. باستخدام Node.js حديث:

```bash
node build.mjs
node --test tests/*.test.cjs
```

أو:

```bash
npm run build
npm test
```

الكريديت مكتوب في `src/index.html` بالنص: **Designed and developed by mohanned**. بعد تعديله، أعد البناء والنشر.

## الاختصارات

- Ctrl / Command + K: بحث عام.
- N: مهمة جديدة خارج حقول الكتابة.
- Space: إيقاف أو استكمال المؤقت داخل صفحة التركيز، أو إظهار إجابة البطاقة.
- Escape: إغلاق النوافذ أو وضع التركيز.
